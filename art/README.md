# Art pass (Phase 2) — Blender, fully scripted, $0

Phase 1 ships `public/3d/room.glb` generated by `scripts/build-blockout.ts`: simple shapes with the final
node names. Phase 2 replaces that one file (plus baked lightmaps) with a real room built and lit in Blender.
No component code changes: behavior binds to node names (`src/lib/scene-contract.ts`) and textures come
from the manifest (`src/lib/assets.ts`).

## Setup

- `brew install --cask blender` (5.2 LTS) — binary: `/Applications/Blender.app/Contents/MacOS/Blender`
- KTX-Software CLI (`ktx`) for UASTC encoding (fallback: basisu)
- CC0 only: ambientCG materials, one Poly Haven HDRI

## Pipeline (`art/blender/`, run headless: `Blender -b --factory-startup -P <script> -- <args>`)

1. `STYLE.md` — palette, bevel sizes, proportions, texel density (write first).
2. `props/*.py` — one script per prop; `lib/` for materials, bevels + weighted normals, naming, UV2 packing.
3. `build_room.py` — assemble per `layout.json`, apply contract names (`obj__*`, `hit__*`, `cam__*`…).
4. `preview.py` — Eevee turntables per prop + a Cycles beauty render → `art/previews/` (review every one).
5. `bake.py` — UV2 lightmap atlas (≥16 px margins), Cycles on Metal, **light-only** Diffuse bakes:
   day (sun + HDRI), night (lamps off), and a light mask with each light alone in one channel
   (R desk lamp, G monitor, B string lights). Slots (book spines, photos) bake with neutral grey stand-ins.
   Denoise in the compositor (not in-bake), tone-map before 8-bit.
6. `export.py` — GLB with UV0 albedo + UV1 lightmap; verify with `gltf-transform inspect`.
7. `scripts/build-assets.mjs` — explicit gltf-transform steps (dedup → prune --keep-leaves → meshopt with
   ≥14-bit UVs; never the default `optimize`), KTX2 encode (2K desktop / 1K mobile, baked mipmaps),
   then `pnpm scene:check` and `pnpm budget:check`.
8. Flip `ASSETS` in `src/lib/assets.ts` to the new files; `createRoomMaterial({ lightmaps })` takes over.
9. `farm.py` — the window diorama (fields, orange orchards, solar arrays, barn, castle hill, animals),
   rendered live into a low-res target with nearest filtering + palette quantization.

## Shader (in `RoomMaterial.ts`, Phase 2 branch)

`L = mix(day, night, n) + n · (mask.r · lamp + mask.g · monitor + mask.b · string)`;
`color = albedo × L` (+ emissive; matcap for glass/metal). `n` = visitor-clock nightness (0..1).

## Budgets
