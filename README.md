# Ömer's Room

An interactive 3D room that is Ömer Öztok's personal site. Click the bookshelf, the computer, the phone,
the window, the framed letter, the globe or the mailbox — each one opens a chapter.

```bash
pnpm install
pnpm dev          # http://localhost:3000
```
